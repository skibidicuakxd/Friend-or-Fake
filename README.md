# Friend or Fake 🎭

Juego para 2 amigos: se hacen preguntas secretas, luego adivinan contra el reloj y ven quién conoce mejor a quién.

## Modo Amigos (disponible)
1. Configura nombres, rondas (1-10), temporizador (5-60s o sin límite) y muerte súbita.
2. Por turnos crean preguntas + respuesta secreta.
3. Se adivinan con timer. 1 punto por acierto (insensible a mayúsculas/tildes).
4. Tabla final + detalle + muerte súbita (1 pregunta extra c/u si empatan).

## Modo Preguntas del cole (pronto)
Preguntas predeterminadas por nivel: Escuela / Colegio / Bachillerato.

## Cómo correrlo

Necesitas Node.js LTS 20+ (https://nodejs.org):

```bash
npm install
npm run dev
```

Abre http://localhost:5173

```bash
npm run build
npm run preview
```
